# 几何后端接口与能力验证

AIDC 使用稳定设置名 `geometry.backend` 选择精确几何实现：

```text
geometry.backend = freecad-occ   # 默认生产后端
```

后端选择与能力验证位于 `aidc_core.geometry`。接口只暴露后端描述、运行时探测和统一验证报告，不向上层泄漏 `TopoDS_Shape` 等原生对象。这样三维发布器、精确干涉服务和 MCP 后续可以在保持结果契约不变的情况下演进实现。

## 命令

查看已注册后端、状态和运行时位置：

```powershell
aidc geometry backends --json
```

验证现有生产后端：

```powershell
aidc geometry validate --backend freecad-occ --report freecad-validation.json --json
```

统一报告采用 `aidc.geometry.validation/0.1`，包含运行时版本、耗时、逐项结果和数值指标。FreeCAD/OpenCascade 验证覆盖基础实体、体积、BRep 布尔求交、最小距离和网格化。

## 运行时边界

`freecad-occ` 是当前唯一后端，并在隔离的 `FreeCADCmd` 进程中运行。正式发行由受管 FreeCAD Runtime Pack 提供执行文件，避免依赖用户自行配置环境变量。

当前阶段只建立后端契约和能力基线，没有切换三维浏览器的生产精确校核服务。完成机器鸭、金刚十轴及异常 CAD 文件的对照验证后，再将精确校核服务接入该选择器。

能力验证只采用可重复构造的盒体基线，不能替代真实机器人 CAD 的生产准入测试。
