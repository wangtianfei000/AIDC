# 验收清单

## 输入和契约

- [ ] 输入格式、schema、版本和哈希已记录。
- [ ] 坐标系、四元数顺序、长度/质量/惯量单位明确且已转换为 SI。
- [ ] body/joint/device/interface 稳定 ID 唯一，引用完整。
- [ ] 根基座、刚体树、关节轴/方向/限位、质量/质心/惯量通过语义校验。
- [ ] 参数来源和证据等级可追溯；估计值被明确标记。
- [ ] 命令、状态和诊断通道的数量、单位、顺序与有效性语义明确。

## 标准库和实现

- [ ] 型号包引用 `AIDCRobotics`，未复制公共方程。
- [ ] 参数差异放在 `DeviceData` 或覆盖文件中。
- [ ] 新公共行为复用稳定接口，并具有 `Examples` 与 `Conformance` 覆盖。
- [ ] 解析接触优先；使用原生网格运行时时已锁定 ABI 和目标平台库。
- [ ] `annotation` 只影响视图，所有物理关系均由组件和 `connect(...)` 表达。

## 生成和工程结构

- [ ] `model-project.json` 的根包、默认实验、Modelica/MSL/AIDCRobotics 版本正确。
- [ ] 包级计数和 ID 数组与 Robot IR/结构清单一致。
- [ ] `Robot`、`UserOverrides`、`Experiment` 职责清楚。
- [ ] 重新生成不会丢失用户覆盖。
- [ ] 相同输入重复生成后，锁文件、结构清单和源码确定一致。
- [ ] 未知 schema、缺字段、坏引用和非法惯量会明确失败。

## 编译和数值行为

- [ ] 在兼容矩阵指定的 OpenModelica/Modelica/MSL 版本上翻译成功。
- [ ] 方程平衡，无未连接关键端口、未知变量或无意义的初始化警告。
- [ ] 默认 `Experiment` 在无界面模式下运行完成。
- [ ] 与能力相关的静态、阶跃、周期、负载、供电或接触场景通过。
- [ ] 关键输出使用显式绝对/相对容差比较，而不是目测曲线。
- [ ] 约束残差、穿透、能量、限位、电流和诊断状态在合理范围。

## 可移植性和回归

- [ ] 便携包不依赖开发机绝对路径。
- [ ] 原生库、资源和许可证随包完整交付，加载失败时有明确诊断。
- [ ] FMU 或跨求解器变量映射、采样和容差已记录。
- [ ] 受影响的标准库、生成器、接触运行时和闭环回归均已运行。
- [ ] 报告包含命令、工具版本、输入/产物哈希、结果位置和失败日志。

## 验收结论分级

使用明确结论，禁止把层级混在一起：

1. **结构验收**：schema、拓扑、单位、参数和接口一致。
2. **工具链验收**：可生成、编译、仿真、比较和打包。
3. **模型行为验收**：声明场景和容差内行为正确。
4. **跨工具验收**：OMC、FMI 或第二求解器结果在容差内一致。
5. **硬件验收**：只有实测台架或机器人数据支持时才能通过。

交付摘要至少列出：已通过层级、关键数值、未通过项、缺失证据、适用边界和下一步。若没有实机数据，显式写出 `hardwareReleaseReady=false`。
