# 初步装配工作流程

## 0. 分清三种结构

开始建模前分别列出 SysML 系统分解、CAD 物理包含关系和关节运动链。CAD 物理树必须在 FreeCAD 文件中用嵌套 `App::Part` 建立；浏览器仅显示这棵树。SysML 与 CAD 使用稳定 ID 映射，不能因为名称相似就自动合并，也不能用发布配置补写 FreeCAD 中缺失的父子关系。

## 1. 冻结本轮配置

在 CAD 中放置任何零件前，先记录：

- 系统型号、版本和本轮装配目的；
- 关节数量、自由度、运动链和左右件关系；
- 执行器、电池、主控、运动控制器、传感器和连接器的确切型号；
- 全局坐标系、长度单位、角度单位和 CAD 工具版本；
- 已冻结项、候选项、缺失项以及对应负责人。

同一用途有两个候选型号时，把它们拆成两个配置，不得叠放到一个主装配中。

## 2. 盘点并登记几何来源

先检查仓库、供应商资料和现有装配，不要直接新建包络。每个零件只选择一个当前生效的几何来源，并记录原文件路径、版本和 SHA-256。

| 状态 | 含义 | 可用于什么判断 |
| --- | --- | --- |
| `VERIFIED_VENDOR_GEOMETRY` | 厂家模型与当前型号、版本和关键尺寸一致 | 外形、接口、干涉和安装 |
| `CONTROLLED_DESIGN_GEOMETRY` | 项目受控的原生设计模型 | 装配、修改和工程交接 |
| `DRAWING_RECONSTRUCTION` | 按正式图纸重建，已知尺寸与假设已分开 | 图纸覆盖范围内的判断 |
| `MEASURED_RECONSTRUCTION` | 按实物测量重建，记录了测量方法和误差 | 测量覆盖范围内的判断 |
| `REFERENCE_MESH` | STL 等参考网格，来源可信但不适合参数修改 | 外形或打印复核 |
| `PLANNING_ENVELOPE` | 仅用于空间预留的包络 | 粗略布局，不能判定接口完成 |
| `CONFIGURATION_CONFLICT` | 型号、版本或来源互相冲突 | 只能登记问题，不能作为主配置结论 |

## 3. 先做接口，再做外观

对高风险模块按下面顺序建模：

1. 放置采购件及其安装基准、轴线和连接器；
2. 放置轴承、轴、套筒、支承面等被动接口件；
3. 设计支架、连接板、紧固件和工具空间；
4. 检查力传递路径、定位方式和紧固方向；
5. 检查安装、拆卸、插拔和换件路径；
6. 完成一个模块验证后，再镜像或复用到其他位置。

采购件模型应保持只读。项目自制件使用可编辑的原生特征，尺寸由命名参数驱动。

## 4. 从模块集成为整机

建议顺序为：单关节接口 → 单腿或单臂 → 躯干与承载结构 → 电池与板卡 → 线束和维护空间 → 整机运动检查。每一级都先消除无解释干涉，再进入下一级。

左右对称结构可以镜像，但仍需分别分配稳定的 `componentId`，并检查接口方向、螺纹方向、连接器朝向和线束出口是否真的对称。

## 5. 管理变更

- 原始 STEP、STL 和图纸保持只读；派生模型记录来源文件和哈希。
- 型号、零件号、版本或关键接口变化时，提升装配修订号并重新运行相关检查。
- 修改不得破坏 SysML、CAD、BOM 和验证记录之间的 `componentId` 映射。
- 无法确认的信息写入 `openItems`，不要把临时假设改写成工程事实。

## 6. 形成可复核交付

交付时同时保存原生 CAD、清单、预览、检查结果和生成脚本。另一位工程师应能在相同工具版本中重建或打开装配，并定位每个关键零件的来源、接口和未关闭项。
