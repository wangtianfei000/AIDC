# 几何与装配契约

## 初步装配所需几何

### 采购件

至少保留主体外形、凸出物、安装面、安装孔或槽、法兰、输出轴、定位基准、被动支承、连接器、出线方向、散热器、排针、镜头和必要禁布区。内部齿轮、电路走线和不影响装配判断的装饰细节可以省略。

### 自制件

至少建立真实外轮廓、壁厚、主要承力截面、通孔与沉孔、定位特征、加强筋、必要圆角、轴承座、紧固件空间和工具空间。影响载荷路径、配合或干涉的形状不得用外包围盒代替。

### 紧固件

紧固件可以使用简化模型，但要保留头部、螺母、垫圈、插入方向和工具包络。初步装配无需建立螺纹牙型，但必须记录规格、数量和有效啮合长度。

## CAD 对象属性

关键零件至少维护下列属性：

| 属性 | 内容 |
| --- | --- |
| `ComponentId` | 与 SysML、BOM 和验证记录一致的稳定 ID |
| `PartNumber` | 厂家型号或项目零件号 |
| `Revision` | 当前几何或设计修订 |
| `GeometryStatus` | 几何来源状态 |
| `GeometrySource` | 原文件、图纸或测量记录 |
| `SourceHash` | 来源文件 SHA-256 |
| `VerificationStatus` | 已核对内容和适用范围 |
| `ParentComponentId` | 装配父项 ID |
| `AssemblyRelation` | 固定、转动、移动或其他关系 |
| `Mass` / `MassSource` | 质量值及厂家、实测或材料计算来源 |
| `ManufacturingStatus` | 初步装配保持 `NOT_RELEASED` |

## 关节与装配关系

每个运动关节都要记录局部轴线、装配零位、上下限、主动侧、从动侧、支承侧和校准方法。仅把零件摆到正确位置不能替代装配关系。固定替代件应建立固定关系并删除已取消执行器，避免质量和干涉重复计算。

装配层级按真实物理包含关系组织：整机、总成、子总成、刚体或零件。边界优先落在可独立采购、制造、验证、更换或随同一刚体运动的对象上。对象名称可读，`componentId` 稳定；不要用树中显示名称代替跨工具标识。

### 层级事实与软件职责

- **FreeCAD/CAD 模型负责定义层级。** `App::Part.Group` 的包含关系、节点内部 ID 和 `Label` 是物理装配树的事实来源，保存后在 FreeCAD 模型树中应直接呈现。
- **浏览软件负责显示层级。** 软件可以提供展开、折叠、搜索、选择、显隐、定位和属性查看，但只能消费模型导出的父子关系，不得根据 SysML 路径、名称规则、几何位置或发布配置重新推断装配树。
- **SysML 模型负责系统语义。** SysML 的组成、功能和接口层级与 CAD 物理树通过 `componentId` 或显式映射追踪；两棵树可以不同，不能用 SysML 分解覆盖 CAD 包含关系。
- **运动关系独立于包含关系。** 关节的主动/从动和运动父子引用物理刚体节点，但不能用关节链自动生成装配包含树。
- **发布器只做投影。** 发布包中的 `bodyId`、`label` 和 `parentBodyId` 必须来自 FreeCAD 模型；禁止用 `bodyLabels`、父子映射表等外部配置修正模型层级。

物理树必须只有一个根装配。每个非根节点只能有一个物理父装配；不得有孤儿、环、重复归属或空标签。规划包络、扫掠体、碰撞代理和验证辅助对象放入独立验证组，不得伪装成物理装配节点。

## FreeCAD 实现建议

- 厂家 STEP 作为只读的独立 `Feature` 导入，并保留源路径、版本和哈希。
- STL 适合参考与打印复核；不得在未确认网格单位、封闭性和版本时直接参与布尔设计。
- 自制件使用 `PartDesign::Body`、完全约束草图和命名参数；避免靠任意缩放匹配接口。
- 使用嵌套 `App::Part` 组织物理装配层级，并设置稳定 `Name`/`BodyId` 与可读 `Label`。叶级实体放入唯一的物理父装配，源几何、派生几何和验证对象分组隔离。
- 构建脚本应在保存前检查单根、唯一父级、无环、无孤儿、标签非空，并在重新打开文件后再次遍历 `App::Part.Group` 验证相同层级。
- 发布器必须从 `App::Part` 递归生成物理树；配置文件只允许声明入口根节点和跨域 ID 映射，不得声明显示标签或父子层级。
- 质量、外廓和碰撞只遍历叶级实体，排除重复聚合体、`Origin`、基准轴和平面等无限几何。
- 保存后重新打开并 `recompute`，确认对象数量、链接、表达式和实体有效。
- 导出 STEP/STL 时记录单位、边界框、实体或网格状态、面片数和 SHA-256。
- 构建脚本应从同一装配生成清单和检查报告，避免手工维护两套事实。

## 包络的允许范围

规划包络仅用于尚未选型的空间预留、运动扫掠区、连接器插拔区、散热区、线束弯曲区和工具区。它不是零件几何。包络必须有独立名称、颜色、`PLANNING_ENVELOPE` 状态和适用说明；只要它承担安装接口或干涉结论，相关检查就不能标记为完成。
