# 验证与退出清单

## 配置与追溯

- [ ] 系统型号、版本、自由度、坐标系和单位已记录。
- [ ] 每一用途只有一个生效硬件型号，候选方案已拆分。
- [ ] SysML、CAD、BOM 和验证记录使用同一组 `componentId`。
- [ ] SysML 分解、CAD 物理包含关系和运动父子关系已分别定义，并用显式 ID 建立追踪。
- [ ] 每个关键几何都有来源、版本、状态和哈希。
- [ ] 所有假设、冲突和缺失资料已进入未关闭项。

## 物理装配树

- [ ] FreeCAD 使用嵌套 `App::Part` 定义物理结构，并在模型树中直接显示可读层级。
- [ ] 物理树只有一个根节点；每个非根节点具有唯一父装配，且不存在孤儿、环或重复归属。
- [ ] 每个物理节点具有稳定内部 ID 和非空 `Label`；显示名称不承担跨工具主键职责。
- [ ] 规划包络、碰撞代理、扫掠体和验证辅助对象未混入物理装配树。
- [ ] 发布配置没有 `bodyLabels` 或父子层级覆盖；发布器直接读取 CAD 模型。
- [ ] 浏览器树与重新打开后的 FreeCAD 树在根、标签、父子关系和节点数量上完全一致。

## 几何与接口

- [ ] 采购件的外廓、孔位、轴线、法兰、连接器和出线方向已核对。
- [ ] 自制件具有真实轮廓、壁厚、孔、定位、支承和紧固结构。
- [ ] 配合间隙、轴向定位、紧固方向和有效啮合长度可检查。
- [ ] 左右件、镜像件和固定替代件没有重复或方向错误。
- [ ] 承担装配结论的对象不是未确认包络。

## 运动与碰撞

- [ ] 关节轴、零位、上下限和父子关系已记录。
- [ ] 中立、极限和典型工作姿态已经检查。
- [ ] 必要时已做连续或足够密集的运动扫掠。
- [ ] 设计接触、共享端点和非预期刚体穿透已分别处理。
- [ ] 所有干涉结果都能定位到两个叶级零件和对应姿态。

## 电子件、线束与维护

- [ ] 电池、主控、控制器、传感器和连接器型号与主配置一致。
- [ ] 连接器插拔、散热、线束弯曲半径和关节活动余量已检查。
- [ ] 电池、板卡、紧固件和高频维护件有可行拆装路径。
- [ ] 工具能够到达关键紧固件，拆装过程不依赖穿过实体。

## 质量与文件完整性

- [ ] 质量和材料来源已记录，未知值没有伪造。
- [ ] 质量、质心和总体外廓只统计叶级实体，没有重复装配体。
- [ ] 原生 CAD 保存并重新打开后能正常重算。
- [ ] 导出的 STEP/STL 单位、边界框、实体或网格状态和哈希已记录。
- [ ] 构建与检查脚本能够重复运行，并生成同一配置的结果。

## 退出状态

分别记录以下状态，不得用一个“通过”替代全部结论：

- `geometryChecksPassed`：文件和几何完整性检查通过；
- `assemblyChecksPassed`：接口、运动、干涉和维护检查通过；
- `p4ExitReady`：初步装配覆盖约定范围，剩余问题已明确接受为详细设计输入；
- `manufacturingReleased`：详细设计、材料、公差、强度、工艺和实物验证均满足正式发布流程。

`p4ExitReady` 可以为真而 `manufacturingReleased` 必须仍为假。只有项目正式完成详细设计和发布审批后，才允许改变制造发布状态。
