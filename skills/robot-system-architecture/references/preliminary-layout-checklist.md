# 初步装配与总体布局检查清单

本清单用于把系统架构交给机械总体设计和 CAD 布局。它不替代详细机械设计、运动学分析或实物验证。

## 身份与层级

- SysML 与 CAD 对象使用相同且唯一的 `componentId`。
- CAD 父子层级与 SysML 装配层级一致。
- 每个部件的父装配明确，固定或运动关系明确。
- 左右件、镜像件和不同版本不会共用 ID。

## 运动与接口

- 每个关节明确轴向、零位、研究限位、驱动端和支承端。
- 安装面、孔位、轴端/花键、紧固件和工具空间有来源。
- 机械安全限位、软件限位和研究动作窗口分别记录。
- 单腿、髋部或其他高载荷接口列为优先验证对象。

## 包络和空间

- 采购件包络区分正式 STEP、厂家尺寸图、实测包络和设计占位体。
- 占位体不会被描述为已核实几何。
- 典型姿态和动作范围内的干涉、净空及夹挤风险有检查任务。
- 电池、板卡、保险、连接器和维护件存在可行拆出路径。
- 紧固方向与装拆工具能够进入。

## 电气、线束和热

- 电源、控制、反馈和接地/回流接口与 SysML 连接一致。
- 线束存在路由空间、固定点、跨关节活动余量和最小弯曲半径。
- 运动范围内不会拉扯连接器或夹伤线束。
- 高功耗设备、电池和驱动器有散热路径、温升假设和验证任务。

## 质量和可追溯性

- 质量、质心和外廓说明数据来源与状态。
- 规划质量、厂家标称和实测质量不混用。
- CAD 汇总值可追溯到部件 ID，并与 SysML 参数分析输入一致。
- 每个待验证包络、接口和质量都有获取资料、测量或试装任务。

## 完成判定

只有在使用真实或明确标注的几何完成检查后，才能声明“无干涉”“可装配”或“可维护”。仅建立 `cadRef`、占位体或示意布局时，应表述为“已交接”“待验证”或“规划可行性待确认”。
