# AIDC host integrations

The files in this directory document the small discovery layer used by AI hosts. The executable implementation remains `bin/aidc-mcp.exe`; host adapters only register that stdio server and the versioned Skills shipped under `skills/`.

Use the CLI so paths are resolved for the current installation and existing host configuration is backed up:

```powershell
aidc integrate codex
aidc integrate cursor
aidc integrate mcp
aidc integrate codex --check
aidc integrate cursor --uninstall
aidc integrate cursor --restore
```

`codex/config.toml` and `cursor/mcp.json` are reference templates. `${AIDC_MCP_EXECUTABLE}` is replaced by the absolute path of the installed `aidc-mcp` binary by the CLI. Generic MCP clients can consume the JSON generated by `aidc integrate mcp`.
