# 干净 Windows 验收基线

## 基线环境

- 主验证平台：干净 Windows 11 x64 虚拟机，安装当期安全更新。
- 兼容性平台：另一条 Windows 11 x64 受支持版本。
- 非管理员本地用户；系统区域分别覆盖中文和英文。
- 快照中不预装 Git、Node.js、Python、FreeCAD、OpenModelica、CMake 或 Visual Studio。
- 一条联网安装通道和一条完全断网通道。

Windows 10 暂不列入正式支持承诺；如实际部署需要，必须增加独立兼容性通道并明确其系统生命周期风险。

## 固定测试矩阵

| ID | 场景 | 通过标准 |
|---|---|---|
| WIN-001 | Core 在线安装 | 非管理员用户完成安装；`aidc version --json` 成功 |
| WIN-002 | Core 离线安装 | 断网环境完成安装，无在线回退 |
| WIN-003 | 宿主接入 | `aidc integrate codex/cursor --check` 通过，重复执行幂等 |
| WIN-004 | SysML | 校验样例并按需打开浏览器，无固定端口配置 |
| WIN-005 | CAD Pack | 安装 FreeCAD，打开 FCStd、无界面发布 STEP/STL/GLB |
| WIN-006 | Modelica Pack | 检查模型、仿真、导出 FMI 2.0、运行 AIDCRobotics 一致性模型 |
| WIN-007 | 三维到 Modelica | 导出 `.aidc-assembly`、生成 Modelica、闭环仿真 |
| WIN-008 | 路径 | 中文、空格和长路径工程均可打开和生成 |
| WIN-009 | 故障 | 端口占用、依赖损坏、低磁盘和服务崩溃返回稳定错误码 |
| WIN-010 | 修复升级 | 修复恢复损坏文件；失败升级回滚到上一可用版本 |
| WIN-011 | 卸载 | 移除程序和宿主接入，不删除用户工程 |
| WIN-012 | 安全 | 服务只监听回环；越权路径和任意命令被拒绝 |

## 证据要求

每次发行候选保存：

- VM 镜像和补丁摘要；
- 安装器与依赖包 SHA-256；
- CLI/MCP 契约版本；
- 每项测试的命令、退出码、结构化结果和日志；
- 进程/端口快照；
- 产物哈希；
- 失败重试与回滚证据。

## P0 状态

测试矩阵与证据格式已冻结。当前工作区尚未产出正式安装器、CLI 或 MCP 可执行文件，因此 WIN-001 至 WIN-012 均处于 `not-run`；P1–P6 必须逐项关闭。
